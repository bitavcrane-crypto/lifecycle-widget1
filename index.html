Як читати оцінку

SQUEEZE EVIDENCEТільки ознаки потенційного перегріву LONG: positive/high funding, OI increase/abnormal growth ≥3%, L/S ≥1.5, 4H extension ≥3%, volume ≥1.5×, RSI ≥70, taker L/S ≥1.5 та short liquidation > long liquidation і ≥0.1% OI quote. Кожен відомий фактор має однакову вагу; недоступні фактори виключаються з бази оцінки. Це не сигнал SHORT.
BEARISH CONFIRMATIONОкремо оцінює закриті 15m свічку, close нижче локальної підтримки/рівня, sell volume +15%, bearish MACD, RSI deterioration, OI реакцію та перевагу long-ліквідацій.
SHORT ENTRY QUALITY35% squeeze + 45% bearish confirmation + 20% якості точки (закриття нижче рівня, bearish candle, sell volume та відстань не більш як 1.5 ATR). Статус входу вимагає окремо: score ≥65, squeeze ≥45, bearish ≥65, point quality ≥50.
Без repaintRSI, MACD, EMA, обсяг та підтвердження використовують лише закриті 4H/15m свічки. Таймфрейми позначені окремо.

Джерела та доступність даних

Усі ринкові значення надходять із публічного Gate.io API v4 для USDT futures. Ціни, 24h-обсяг і funding — tickers; funding interval — contracts; свічки — candlesticks; OI, L/S ratios і направлені ліквідації — contract_stats; історія funding — funding_rate. Long/short ratio, top-trader ratio, taker ratio та liquidation events відображаються лише якщо Gate.io повертає відповідні поля. Немає API-значення — показується N/A, а не нуль. Офіційна документація Gate.io
Дані: публічний API Gate.io v4, USDT-M perpetual futures. Обсяг свічки — у контрактах; 24h quote volume та OI quote value позначаються окремо. 4H використовується для перегріву, 15m — для підтвердження. Дані не є персоналізованими чи інвестиційною рекомендацією; ринкові ціни та якість API можуть змінюватися.
