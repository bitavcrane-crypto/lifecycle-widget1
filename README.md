# Ринковий радар

Односторінковий віджет для спостереження за безстроковими USDT-ф'ючерсами Binance. Інтерфейс та пояснення сигналів — українською.

## Запуск

Відкрийте `index.html` у сучасному браузері з доступом до `https://fapi.binance.com`. Список пар зберігається у локальному сховищі браузера. Можна додавати та видаляти пари (до 30); сканер ринку показує безстрокові USDT-пари зі зміною ціни від 8% за 24 години та обсягом від 5 млн USDT. Дані оновлюються щохвилини.

## Сигнали й обмеження

- Оцінка кандидата на шорт враховує RSI за годинними свічками, фандінг, зміну відкритого інтересу між оновленнями та близькість до локального максимуму. Орієнтовний діапазон показується лише за трьох із чотирьох умов; він не є гарантованим або «безпечним» входом.
- Сигнал «Мертвий кит» — умовна назва для комбінації незвично високого годинного обсягу, руху ціни та зниження відкритого інтересу. Це не ончейн-детектор: він не бачить гаманці, ліквідації чи перекази та не може підтвердити діяльність конкретного великого власника.
- Сканер та оцінки спираються лише на публічні дані Binance USDⓈ-M Futures; технічні дані або котирування можуть бути недоступні для окремої пари. Віджет не надає інвестиційних рекомендацій. «Безпечного шорту» не існує.
