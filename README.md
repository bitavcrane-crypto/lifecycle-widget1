# lifecycle-widget1
Максимум сквізу невизначати безпечний шорт. Порядок дій:  перевірити, чи переповнені шорти або лонги;  оцінити ціну, обсяг і RSI;  врахувати фандінг, відкритий інтерес і карту ліквідацій;  стежити за переказами великих холдерів на біржі;  чекати підтвердження розвороту закриттям під рівнем;  ставити стоп над максимумом.
